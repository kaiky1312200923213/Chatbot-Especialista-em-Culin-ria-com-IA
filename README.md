# Chef Carlos — Chatbot de Culinária com IA

**Autor:** Kaiky Yoshio Ono Marins  
**Categoria:** Python · Chatbots · IA generativa  
**Status:** Protótipo de estudo

## Visão geral

Chatbot de terminal com persona de especialista em culinária. O exemplo configura um agente chamado Chef Carlos para responder sobre receitas, ingredientes e técnicas de cozinha em tom amigável.

## O que demonstra

- Definição de persona e instruções para um agente.
- Envio de mensagens para um modelo de linguagem.
- Loop de conversa no terminal.
- Delimitação do domínio de respostas ao tema culinária.

## Tecnologias

- Python
- Agno
- SDK compatível com OpenAI
- NVIDIA NIM / Llama
